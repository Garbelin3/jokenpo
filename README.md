# ✊✋✌️ Jogo de Jokenpo (Pedra, Papel e Tesoura) ✊✋✌️

Bem-vindo ao **Jokenpo**! Prepare-se para um duelo contra a máquina em uma partida clássica de *Pedra, Papel e Tesoura*. Será que você consegue vencê-la? 😏

## 🎮 Como Funciona?

1. **Faça sua escolha:** Selecione Pedra, Papel ou Tesoura.
2. **A máquina faz a jogada:** A máquina escolhe uma opção aleatoriamente.
3. **Resultado:** O jogo compara as jogadas e define o vencedor. Você receberá no console uma mensagem indicando se venceu, perdeu ou empatou.

## 🧠 Regras do Jogo

As regras são simples e seguem as lógicas clássicas:

- **Pedra** vence **Tesoura**
- **Tesoura** vence **Papel**
- **Papel** vence **Pedra**
- Opções iguais resultam em **empate**

## 🚀 Como Jogar

1. Clone o repositório e entre na pasta do projeto:

   ```bash
   git clone https://github.com/Garbelin3/jokenpo.git
   cd jokenpo
   ```

2. Inicie o jogo:

   ```bash
   go run .
   ```

3. Siga as instruções no console para fazer sua escolha, e veja o resultado da rodada.

## 🔥 Exemplo de Rodada

1. **Você escolhe:** Papel
2. **Máquina escolhe:** Pedra
3. **Resultado:** Você vence! 🎉 (Papel vence Pedra)

**Boa sorte e que vença o melhor!**
